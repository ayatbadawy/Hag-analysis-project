🕋 Hajj & Umrah Data Analysis Project
📝 Overview
This project is a Data Analysis and Visualization project for Hajj & Umrah services using Power BI.
It focuses on understanding the distribution of pilgrims, performance indicators, and service trends to help improve planning and decision-making.
🎯 Objectives
Analyze data related to Hajj & Umrah pilgrims
Understand distribution by country, season, and service type
Identify trends in demand and performance
Provide clear insights through interactive dashboards
🛠️ Tools Used
Power BI
Excel (Data Cleaning & Preparation)
Data Modeling
DAX Measures (if used)
📊 Dashboard Features
Interactive filters (Slicers for country, year, season)
KPI cards (Total pilgrims, counts, etc.)
Charts for comparison between regions
Trend analysis over time
Clean and simple UI for better decision making
🔍 Key Insights
Pilgrim distribution varies significantly by country and season
Peak demand periods can be clearly identified
Certain regions show higher participation trends
Data helps improve planning and resource allocation
📁 Files Included
Power BI Dashboard (.pbix)
Dataset (Excel file)
README file
🚀 Conclusion
This project demonstrates how data analysis can support better planning in Hajj & Umrah operations, by transforming raw data into meaningful insights using Power BI.
